# 이미지 업로드 가이드

## 📁 폴더 구조

### hero/ - 페이지 히어로 이미지
- `home-hero.jpg` - 홈페이지 배경
- `stream-hero.jpg` - 중랑천 페이지 배경
- `mountain-hero.jpg` - 산 페이지 배경
- `species-hero.jpg` - 종 가이드 페이지 배경
- `observations-hero.jpg` - 관찰 기록 페이지 배경

권장 크기: 1920x1080px 이상

### cards/ - Field Observations 카드 이미지
- `stream-card-01.jpg` ~ `stream-card-08.jpg` - 중랑천 관찰 카드
- `mountain-card-01.jpg` ~ `mountain-card-10.jpg` - 산 관찰 카드

권장 크기: 800x600px 이상 (4:3 비율)

## 📤 업로드 방법

1. GitHub 저장소 접속: https://github.com/CassianK/Nature-report
2. **branch-1** 브랜치 선택
3. `public/images/hero/` 또는 `public/images/cards/` 폴더로 이동
4. "Add file" → "Upload files" 클릭
5. 위 파일명으로 이미지 업로드
6. 커밋 메시지 작성 후 "Commit changes" 클릭

## ⚠️ 주의사항

- 파일명은 정확히 일치해야 합니다 (대소문자 구분)
- 파일 형식은 `.jpg` 또는 `.png`
- 이미지 크기가 너무 크면 (5MB 이상) 압축 권장
